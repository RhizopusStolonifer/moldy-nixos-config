Thanks for downloading my cursors! :D
Here's a guide for how to apply them in case you've never done it before.
This guide is for Windows because that's all I'm familiar with lol

In the Start Menu, search for "Mouse Settings." Then, find the button that says "Additional mouse settings." Click on that and go to the second tab, the one that says "Pointers." Here, you can see all your different cursors and the icons included in them.

In the folder you downloaded, there should be files that correspond to each of the icon names listed. To add them, go down the list double clicking each icon and then select the icon you want to apply to it. Once you've replaced all of them, you can Apply it! Make sure to "Save As" a new Scheme. This will save your cursor. You can view all your saved schemes by clicking on the dropdown menu.
